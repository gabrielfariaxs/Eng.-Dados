# Backlog Técnico - LicitaMEI

Lista de requisitos e funcionalidades priorizadas para o desenvolvimento do MVP.

## Épicos e Histórias de Usuário

### Épico 1: Descoberta de Oportunidades
- **História 1**: Como MEI, quero buscar editais por palavra-chave para encontrar oportunidades no meu setor.
- **História 2**: Como MEI, quero filtrar editais por valor e região para focar em licitações viáveis para meu negócio.

### Épico 2: Gestão de Habilitação
- **História 3**: Como MEI, quero ter um checklist automático da Lei 14.133 para saber se estou apto a participar.
- **História 4**: Como MEI, quero organizar meus documentos (CCMEI, certidões) para não perder prazos por falta de papelada.

### Épico 3: Acompanhamento e Alertas
- **História 5**: Como MEI, quero receber alertas de prazos para garantir que minha proposta seja enviada a tempo.
- **História 6**: Como MEI, quero um dashboard simples para ver em quantas licitações já participei.

## Critérios de Aceite
- O app deve ser mobile-first (React Native).
- Persistência de dados deve funcionar offline (AsyncStorage).
- Interface deve seguir as regras da Nova Lei de Licitações.
